Что умеет

Внутри NX поднимается MCP-сервер с семантическими инструментами nx_*, а окно чата запускает Claude Code или OpenAI Codex как агентный рантайм. Агент сам проходит цикл «изучить → изменить → измерить → проверить → посмотреть».

80+ инструментов NX

Эскизы, экструзия, отверстия, скругления, оболочки, loft, sweep, массивы, поверхности, импорт STEP/STL.

Проверка результата

Измерения, габариты, число тел, ошибки обновления и скриншоты: агент проверяет, что получилось.

Undo на каждый шаг

Каждое изменение — чекпоинт. Режимы одобрения: спрашивать всегда, только о рискованном или не спрашивать.

Выделение в чате

Выделенные в NX грани и рёбра уходят в сообщение, @-упоминания объектов, ссылки в ответах подсвечивают модель.

Claude Code и Codex

Установка и вход в агента прямо из плагина, без терминала. Плагин не хранит пароли и токены.

Любой MCP-клиент

Сервер на 127.0.0.1:7421/mcp подходит для Claude Code, Codex, OpenCode и других клиентов.

Установка

Права администратора и .NET SDK не нужны. Дальше плагин обновляется сам.

  1. Скачай архив

    NxAgent-0.5.6.zip и распакуй в любую папку.

  2. Запусти Install.cmd

    Установщик скопирует плагин в %LOCALAPPDATA%\nx-agent и зарегистрирует его в NX.

  3. Открой NX

    Menu → AI Agent → Open AI Chat или Ctrl+Shift+L. Новые версии приходят баннером в чате.

Требования

  • Windows 11 и Siemens Designcenter NX 2512 с лицензией dotnet_author.
  • .NET 8 Desktop Runtime и Microsoft Edge WebView2 Runtime (на Windows 11 уже есть).
  • Аккаунт Claude Code или OpenAI Codex; оба ставятся и авторизуются из плагина.
